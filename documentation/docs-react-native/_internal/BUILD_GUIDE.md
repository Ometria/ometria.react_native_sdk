# Build Guide

How to build the sample apps for each configuration.

---

## Prerequisites

Install dependencies from the repo root first:

```sh
pnpm install
```

---

## Non-Expo Sample App (`example/`)

The `example/` app supports both Old and New Architecture. All commands are run from the **repo root**.

### iOS — New Architecture (default)

```sh
# Install pods with New Arch enabled
pnpm example ios:new:pods

# Run on simulator
pnpm example ios:new
```

Or open `example/ios/sampleApp.xcworkspace` in Xcode and run from there.

### iOS — Old Architecture

```sh
# Install pods with Old Arch
pnpm example ios:old:pods

# Run on simulator
pnpm example ios:old
```

> Switching between architectures requires re-running the matching `:pods` command first.

### Android — New Architecture (default)

```sh
pnpm example android:new
```

Or open `example/android/` in Android Studio. Make sure `newArchEnabled=true` is set in `example/android/gradle.properties`.

### Android — Old Architecture

```sh
pnpm example android:old
```

Or open in Android Studio and set `newArchEnabled=false` in `example/android/gradle.properties`.

## Expo Sample App (`example-expo/`)

The Expo app supports **New Architecture only**.

### Generate native projects (prebuild)

Native `ios/` and `android/` folders are generated by Expo. Run prebuild whenever `app.json`, plugins, or dependencies change:

```sh
cd example-expo
npx expo prebuild
```

> Note: this regenerates the Podfile and native files. Any manual edits to `ios/` or `android/` will be overwritten.

### iOS

```sh
# After prebuild, install pods
cd example-expo/ios && pod install

# Run on simulator (from example-expo/)
npx expo run:ios
```

Or open `example-expo/ios/<AppName>.xcworkspace` in Xcode and run from there.

### Android

```sh
# From example-expo/
npx expo run:android
```

Or open `example-expo/android/` in Android Studio and run.

## Architecture toggle reference

| App | New Arch | Old Arch |
|-----|----------|----------|
| `example` iOS | `RCT_NEW_ARCH_ENABLED=1` (default) | `RCT_NEW_ARCH_ENABLED=0` |
| `example` Android | `newArchEnabled=true` in gradle.properties | `newArchEnabled=false` |
| `example-expo` | New Arch only | Not supported |
